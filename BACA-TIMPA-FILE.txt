CARA PAKAI
1. Ekstrak zip ini, lalu salin SEMUA folder (app, components, lib) ke folder repo SI-LIPU. Pilih "Timpa / Replace" bila ditanya.
2. Jalankan:  npm run dev   (atau npm run build) lalu buka /dashboard/pilkades
3. Tidak ada migrasi database baru. Tidak ada paket baru.

CATATAN

  Mau dilonggarkan? Di app/dashboard/pilkades/daftar/page.js ubah  const alasanDps = s.alasanTetapkan;  menjadi  const alasanDps = s.memenuhi === 0 ? s.alasanTetapkan : null;
