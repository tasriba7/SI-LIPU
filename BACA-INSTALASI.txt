BANNER HALAMAN - SI-LIPU
=========================
Isi zip ini adalah file yang BARU atau BERUBAH, dengan struktur folder yang sama
seperti proyek Anda.

Cara pasang:
1. Ekstrak zip ini langsung ke folder utama proyek SI-LIPU
   (pilih "Replace/Timpa" bila ditanya).
2. Jalankan supabase/migrations/0039_banner_halaman.sql di Supabase SQL Editor.
3. Commit & push (atau deploy) seperti biasa.
4. Login sebagai admin -> Pengaturan Desa -> Banner Halaman -> unggah gambar.
