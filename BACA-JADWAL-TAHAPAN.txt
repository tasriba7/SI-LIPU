Pilkades: Jadwal Tahapan yang bisa diatur + progres visual di beranda
Dibuat di atas commit main 8f4b362. Paket KUMULATIF: sudah termasuk perapian pesan
(BACA-RAPIKAN-PESAN.txt). Aman ditimpa walau paket sebelumnya sudah dipasang.

CARA PASANG
1. Supabase SQL Editor: jalankan supabase/migrations/0062_pilkades_jadwal_tahapan.sql
   (sesudah 0051-0061). Bila versi 0062 yang lama sudah pernah dijalankan, aman dijalankan lagi:
   tabel lama diganti bentuk baru (tanggal jadwal lama perlu diisi ulang).
   Lalu boleh jalankan supabase/verifikasi_0062.sql (hanya membaca).
2. Ekstrak zip, salin folder app, components, lib, supabase ke repo. Pilih "Timpa / Replace".
3. npm run dev, buka /dashboard/pilkades. Tidak ada paket baru.

CARA PAKAI (panitia): menu "Jadwal Tahapan"
- Ganti nama tahapan: ketik langsung di kolom nama.
- Ubah urutan: tombol panah naik/turun. Hapus: tombol tong sampah. Tambah: "+ Tambah tahapan".
- "Kembalikan ke daftar standar": mengisi ulang 10 tahapan bawaan.
- Tidak ada yang tersimpan sebelum menekan "Simpan jadwal" (ada penanda "perubahan belum disimpan").
- Maksimal 30 tahapan. Tanggal selesai kosong = satu hari.

OTOMATISASI (tetap jalan)
Tahap bertanda ⚙ selesai sendiri saat pekerjaannya tercatat di aplikasi, walau namanya diganti
atau urutannya dipindah:
  Penyusunan Daftar Pemilih -> DPS ditetapkan | Penetapan DPT -> DPT ditetapkan
  Penetapan Calon -> ada calon berstatus Ditetapkan | Calon Terpilih -> calon terpilih ditetapkan
  Pemungutan Suara -> tanggal mengikuti menu Periode (Administrator); tahap ini tidak bisa dihapus.
Bila tahap otomatis dihapus, otomatisasi tahap itu ikut hilang; "Kembalikan ke daftar standar" memulihkannya.
Tahap lain (termasuk yang ditambah sendiri): selesai bila tanggalnya sudah lewat.
Status: Selesai (hijau) | Berlangsung (biru) | Akan datang | Terlewat (kuning: jadwal lewat tapi data belum
tercatat) | Belum dijadwalkan (abu-abu). Acuan hari ini = WITA.

BERANDA: kartu "Progres pelaksanaan" (cincin persen, tahap berjalan, hitung mundur H-xx, bilah segmen)
+ garis waktu tahapan sesuai urutan yang diatur panitia. Admin hanya melihat.
